Predictive Maintenance Monitor

Description: A low-cost industrial sensor monitoring system built in C, deployed to Arduino hardware, with a live Python dashboard. Detects early warning signs of equipment failure — overheating, abnormal vibration, and excessive current draw — before a breakdown occurs.

The Problem It Solves: Small workshops and factories run motors, compressors, and pumps that fail unexpectedly. Large companies solve this with expensive industrial IoT systems costing thousands. This project provides the same early-warning capability for under $70 in hardware.

Technologies Used:

  • C11 (GCC / MinGW) - Embedded layer
  • Arduino (C++ / AVR) - Microcontroller programming
  • Python 3 - matplotlib, pandas, pyserial for dashboard
  • I2C Protocol - Sensor communication
  • VS Code + Arduino IDE

Hardware Components:

  • Arduino Uno - Microcontroller
  • DHT11 - Temperature + humidity sensor
  • MPU6050 (GY-521) - Vibration / accelerometer
  • ACS712 5A - Current draw sensor (coming soon)

Key Features:

  • Circular ring buffer implementation using pointer arithmetic
  • Multi-sensor coordination with threshold-based alerts
  • Live Python dashboard with color-coded warnings (blue=normal, orange=warning, red=critical)
  • CSV data logging and real-time serial communication
  • Comprehensive test suite: 127 assertions across 3 test files, 0 failures

Alert Thresholds:

  • Temperature: Warning >70°C, Critical >85°C
  • Humidity: Warning <20% or >80%
  • Vibration: Warning >0.5g, Critical >1.0g
  • Current: Warning >8A, Critical >10A (coming soon)

Skills Demonstrated:

  • Embedded C programming with manual memory management
  • Pointer arithmetic and ring buffer implementation
  • Layered software architecture (buffer, sensor, manager layers)
  • I2C communication protocol
  • Cross-language integration (C ↔ Python)
  • Unit testing and test-driven development
  • Hardware prototyping and sensor integration

Technical Implementation:

  • Circular buffer with head/tail pointers and wrap-around logic
  • Two-stage malloc with defensive cleanup
  • State machine for sensor management
  • CSV streaming over USB at 9600 baud
  • Matplotlib animations for live data visualization
